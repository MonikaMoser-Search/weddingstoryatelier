Vorderseite: Menü eintragen. Rückseite: je Gericht „Allergene wählen" antippen — die Allergen-Liste entsteht von selbst. Danach „Drucken / PDF". Tipp: im Druckdialog Hintergrundgrafiken aktivieren.
Heimdruck: Vorder- und Rückseite kommen nebeneinander auf ein A4-Blatt — an der gestrichelten Mittellinie nach hinten falzen, fertig (DL, 99 × 210 mm). Druckerei: randlose DL-Karte mit 3 mm Beschnitt, eine Seite je Karte.

So tragen Sie die Allergene ein

  1. Tragen Sie zuerst auf der Vorderseite Ihr Menü ein — jedes Gericht erscheint dann automatisch auf der Karte unten.
  2. Tippen Sie bei einem Gericht auf „Allergene wählen" — die Auswahl klappt auf. Markieren Sie alle zutreffenden Allergene.
  3. Tippen Sie erneut auf „Allergene", um die Auswahl wieder einzuklappen — so sehen Sie die fertige Vorschau.
  4. Zum Schluss oben auf „Drucken / PDF". Die Hinweise hier werden nicht mitgedruckt.
