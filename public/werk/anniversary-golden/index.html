Brief-Empfänger

Ein Eintrag pro Haushalt (1 Brief). Paare und Familien gemeinsam — die Aufteilung in einzelne Platzkarten erfolgt später im Platzkarten-Tab.

Format: Name [,m|,f] [| Brief-Vorname]
• ,m = „Lieber" · ohne Suffix = „Liebe"
• | Brief-Vorname macht den Brief intim (z. B. „Liebe Sofie" statt „Liebe Sofie Hofmann")

Programm-Slots

Eine Zeile pro Slot. Format: Zeit | Titel | Untertitel — Untertitel optional. Max. 6 Slots empfohlen, damit die Timeline lesbar bleibt.

Aus Brief-Liste übernehmen

Brief-Liste = Haushalte (1 pro Brief). Platzkarten = Personen. Der Bridge-Button splittet Paare an „&" auf — Familien-Einträge bleiben als eine Zeile und müssen manuell aufgeteilt werden.

Platzkarten-Personen

Ein Name pro Zeile — max. 60. Jede Zeile wird eine eigene Karte.
